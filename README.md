# 🎓 College Discovery Platform

A full-stack web application that helps students discover, compare, and save colleges based on their preferences.

## 🔗 Live Demo
[Click here to view the live site](https://college-discovery-platform-vert.vercel.app/)

## ✨ Features
- 🔍 Search colleges by name
- 📍 Filter colleges by location
- 📄 View detailed college info (Courses, Placements, Reviews)
- ❤️ Save favorite colleges
- ⚖️ Compare colleges side by side
- 🎯 College Predictor Tool
- 🔐 Login & Signup pages

## 🛠️ Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Deployment:** Vercel
- **Version Control:** GitHub

## 🚀 Getting Started

```bash
git clone https://github.com/sujitha611/college-discovery-platform.git
cd college-discovery-platform
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
